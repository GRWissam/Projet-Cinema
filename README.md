# 🎬 Projet Cinéma - Interface Native JS

Une application web interactive pour explorer l'univers du cinéma, réalisée en JavaScript pur.

## 📝 Présentation
Ce projet a été réalisé pour pratiquer les bases du développement Web Front-end. L'objectif était de créer une interface dynamique capable d'afficher des films et de gérer des interactions utilisateurs sans framework complexe.

## 🛠️ Technologies Utilisées
- **HTML5** : Structure sémantique de l'application.
- **CSS3** : Design responsive et animations (Flexbox/Grid).
- **JavaScript (Vanilla)** : Manipulation du DOM, gestion des événements et logique de filtrage.

## 📌 Points Clés de l'Apprentissage
- **Gestion des Événements** : Mise en place de l'interactivité (clics, survol).
- **Architecture de fichiers** : Organisation propre entre le HTML, le CSS et le script JS.
- **Design Responsif** : Adaptation de la galerie de films pour tous les écrans.
